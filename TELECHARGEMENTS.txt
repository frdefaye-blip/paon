PAON — Ajouter une version à télécharger

Les fiches affichent automatiquement les fichiers des Releases publiques du dépôt PAON.
Les descriptions restent modifiables directement dans les HTML (indentation : 4 espaces).

1. Ouvrir https://github.com/frdefaye-blip/paon/releases
2. Cliquer sur « Create a new release » / « Draft a new release ».
3. Créer un tag propre à l'application : tada-v0.6.0, adapdf-v0.3.2, geomada-v0.2.0.
4. Donner un titre clair : « TAda 0.6.0 », par exemple.
5. Ajouter les nouveautés et déposer les installateurs dans la zone des fichiers joints.
6. Publier la Release. Les boutons apparaîtront automatiquement sur la fiche correspondante.

Faire une Release par application et par version. Joindre tous les formats de cette version à la même Release.
La version publiée le plus récemment apparaît en premier, les autres dans « Versions précédentes ».
Les brouillons et les préversions (« pre-release ») ne sont pas affichés sur le site.
Les 100 Releases les plus récentes sont consultées. Toutes restent accessibles via le lien GitHub.

Noms reconnus (sans distinction majuscules/minuscules) :
- TAda_... ou TAda-...
- adaPDF_... ou adaPDF-...
- GeomADA_... ou GéomADA_... (également avec un tiret)
Formats reconnus : .exe, .msi, .deb, .AppImage, .apk, .dmg, .zip.
La taille est obtenue automatiquement depuis GitHub.

Fichiers locaux repérés, à choisir et valider avant publication :
TAda : 
  TAda_0.6.0_x64-setup.exe
  TAda_0.6.0_windows-x64-portable.exe
  Plusieurs variantes de travail (dictee, ordinaux) existent : elles ne sont pas publiées automatiquement.
adaPDF : 
  adaPDF_0.3.2_x64-setup.exe
  adaPDF-Windows-0.3.2-portable.exe
GeomADA : 
  GéomADA_0.2.0_x64-setup.exe
  GeomADA_0.2.0_Windows_x64_portable.exe
  GeomADA_0.2.0_amd64.deb

Aucun installateur n'a encore été téléversé. Les dépôts des applications ne sont pas accessibles publiquement.
Le dépôt PAON permet de distribuer les installateurs sans publier le code source des applications.
Ne pas ajouter les installateurs aux fichiers du site : les joindre uniquement aux Releases.
