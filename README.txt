PAON — maquette HTML / CSS / JavaScript
Ouvrir index.html dans un navigateur. Aucun serveur ni installation nécessaire.
Pages : index.html, tada.html, adapdf.html, geomada.html.
styles.css : apparence commune. script.js : retour en haut des fiches.
Les descriptions sont provisoires. Aucun numéro de version ou système compatible n'est présumé.
Pour ajouter un téléchargement, remplacer le statut À venir par :
<a class="button" href="URL_DU_FICHIER">Télécharger</a>
Indiquer le numéro, le système, le format, la taille et la date réels.
Pour chaque version précédente, ajouter une entrée dans le bloc details.
Hébergement conseillé : GitHub Pages pour les pages, GitHub Releases pour les installateurs.
Autre possibilité : Cloudflare Pages pour le site, GitHub Releases pour les fichiers.
Publier uniquement les fichiers du site et les fichiers réellement destinés au public.
